# think v2.0 — разбор выбора для любой ИИ

Спарринг-партнёр для решений: какое действие, какую цель, от чего отказаться. Пять слоёв (ограничение → рычаг → альтернативная стоимость → энергия → отбор и асимметрия), три режима (ЛУПА / КАРТА / АЙСБЕРГ), интервью до вердикта, каталог 15 промахов, журнал решений со сверкой обещаний.

Один и тот же текст работает в Claude Code, Claude Projects, ChatGPT, Gemini, Telegram-боте и в любой модели через API. Ничего личного внутри: всё о человеке живёт в его журнале.

## Устройство

```
core/system-prompt.md   ядро: кто, тон, машина состояний Ш0–Ш6, шпаргалка на случай без модулей
modules/                по одному правилу в одном месте
  memory.md             уровни памяти, формат журнала, блок «ЖУРНАЛ — обнови»
  interview.md          как спрашивать, минимум по режимам, онбординг
  modes.md              шаблоны ЛУПА / КАРТА / АЙСБЕРГ
  layers.md             пять слоёв
  goals.md              блок «Цели»
  misses.md             15 промахов
adapters/               как поставить на конкретную платформу
dist/                   собирается build.py — руками не править
tests/scenarios.md      8 сценариев ручной проверки + журналы-фикстуры
```

Правишь только `core/` и `modules/`, потом `python build.py`. Скрипт собирает `dist/`, печатает размеры и падает, если compact длиннее 7500 символов, если в нейтральных файлах появились платформенные слова или ядро ссылается на несуществующий модуль.

## Установка

| Платформа | Что куда | Подробно |
|---|---|---|
| **Claude Code** | скопировать `dist/claude-code/think/` в `~/.claude/skills/think/` | `adapters/claude-code/SKILL.md` |
| **Claude Projects** | `core/system-prompt.md` → инструкции проекта; `modules/*.md` + журнал → знания | `adapters/claude-projects.md` |
| **ChatGPT Custom GPT** | `dist/think-compact.md` → Instructions; `modules/*.md` → Knowledge | `adapters/chatgpt.md` |
| **ChatGPT Projects** | `dist/think-single.md` → инструкции проекта; журнал → файлы | `adapters/chatgpt.md` |
| **Gemini Gem** | `dist/think-single.md` → Instructions; журнал → файлы | `adapters/gemini-gem.md` |
| **Telegram-бот** | `dist/think-single.md` + журнал на пользователя в SQLite | `adapters/telegram-bot.md` |
| **Любая модель по API** | `dist/think-single.md` + служебный блок с датой и журналом | `adapters/api.md` |

Claude Code, подробнее:
1. `python build.py`.
2. Старый навык сохрани: переименуй `~/.claude/skills/think/` в `think-v1` (и смени у него `name:` во frontmatter, чтобы имена не совпадали) или убери из папки навыков.
3. Скопируй содержимое `dist/claude-code/think/` в `~/.claude/skills/think/`. Журнал `~/.claude/think-journal.md` подхватится как есть.
4. Попробовать рядом со старым, не заменяя: положи в `~/.claude/skills/think-v2/` и поменяй `name: think` на `name: think-v2` в его SKILL.md.

## Память

Ядро само выбирает уровень по тому, что ему доступно (`modules/memory.md`):

| Уровень | Где | Как пишется журнал |
|---|---|---|
| 1 | Claude Code (файл), бот или API (хранит программа) | модель пишет сама, или выдаёт блок, а программа его применяет и скрывает |
| 2 | ChatGPT / Claude Projects / Gemini с журналом в файлах и памятью платформы | короткое — в память платформы; полный журнал — блоком, человек обновляет файл |
| 3 | голый чат | в начале человек вставляет журнал; в конце КАРТЫ / АЙСБЕРГА / онбординга модель выдаёт блок «ЖУРНАЛ — обнови» |

Блок обновления — код-блок `journal` с маркерами `<!-- replace: <заголовок> -->`, `<!-- append -->`, `<!-- full -->`. Человек применяет его руками, программа — функцией `apply_update` из `adapters/api.md`.

Формат журнала совместим с v1: `# Профиль`, `# Действующие решения`, `## Парковка идей`, записи `## YYYY-MM-DD · режим · тема`. Старый журнал работает без переделки.
